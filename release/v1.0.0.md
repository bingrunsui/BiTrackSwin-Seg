# BiTrackSwin-Seg v1.0.0

This release packages the selected RAW model from the best local single-stream
training checkpoint. It is a 5-band multispectral segmentation model, not a
two-stream multimodal checkpoint.

## Selected artifact

- File: `bitrackswin_seg_v1_raw.pth`
- Source checkpoint: `best.pth`, epoch 95
- Selection metric: mIoU `0.8759134275714613`
- Exported state: `model_state_dict` (RAW), not `ema_state_dict`
- Architecture configuration: `three_stage` backbone with a U-Net pixel decoder
- Trainable parameters: `13,441,205`
- State-dict elements: `13,441,277` across `369` tensors (including 72 buffer elements)
- Artifact size: `53,887,062` bytes
- SHA256: `2067e038d9fc177d43605d7087463bafa297aadef091b5a6384b1ccf4a60a4b1`

The attached `.pth` is a weights-only artifact. It contains exactly
`model_state_dict` and small metadata; it excludes optimizer, scheduler, AMP
scaler, RNG state, and EMA weights. Verify its SHA256 against
`v1.0.0-metadata.json` before use.

## Load contract

```python
payload = torch.load("bitrackswin_seg_v1_raw.pth", map_location="cpu", weights_only=True)
model.load_state_dict(payload["model_state_dict"], strict=True)
```

Use the matching v1 configuration and model implementation. The release test
checks artifact structure and integrity but deliberately does not instantiate a
model; the repository's evaluation entry point performs the strict model-load
check.
